FIRDOUS SAUD AL-SHARHAN LAW FIRM - CPANEL DEPLOYMENT GUIDE
================================================================

📁 FILES TO UPLOAD TO CPANEL:

1. FRONTEND FILES (Upload to public_html/):
   ├── Copy everything from: dist/public/
   │   ├── index.html
   │   ├── assets/ (CSS & JS files)
   │   └── images/ (your Saudi legal images)

2. BACKEND FILES (Upload to your domain folder root):
   ├── dist/index.js (your server file)
   ├── data/ (your JSON database files)
   ├── package.json
   └── node_modules/ (if needed)

📋 CPANEL DEPLOYMENT STEPS:

Step 1: Upload Frontend Files
-----------------------------
- Go to cPanel → File Manager
- Navigate to public_html/
- Upload everything from dist/public/ folder
- Your website structure should look like:
  public_html/
  ├── index.html
  ├── assets/
  └── images/

Step 2: Upload Backend Files  
----------------------------
- Stay in your domain root folder (usually one level up from public_html)
- Upload: dist/index.js
- Upload: data/ folder (contains your news articles)
- Upload: package.json

Step 3: Install Dependencies
---------------------------
- In cPanel Terminal (or SSH), run:
  npm install --production

Step 4: Configure Node.js App
-----------------------------
- Go to cPanel → Node.js Apps
- Click "Create App"
- Set:
  - Node.js Version: Latest available
  - Application Mode: Production
  - Application Root: / (your domain root)
  - Application URL: your domain name
  - Startup File: dist/index.js

Step 5: Start Your App
----------------------
- Click "Start App"
- Your law firm website should now be live!
